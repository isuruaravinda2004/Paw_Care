# Official references

The code and guide are original project material. These primary references explain the underlying tools and API:

- Apache NetBeans, Introduction to GUI Building: https://netbeans.apache.org/tutorial/main/kb/docs/java/gui-functionality/
- Apache NetBeans, Designing a Swing GUI: https://netbeans.apache.org/tutorial/main/kb/docs/java/quickstart-gui/
- Apache NetBeans, Maven Swing application tutorial: https://netbeans.apache.org/tutorial/main/kb/docs/java/maven-hib-java-se/ (used only for Maven/Swing workflow; this project does not use Hibernate).
- JasperReports 6.21.3 query sample: https://jasperreports.sourceforge.net/6.21.3/sample.reference/query/index.html
- JasperReports 6.21.3 compiler API: https://jasperreports.sourceforge.net/6.21.3/api/net/sf/jasperreports/engine/JasperCompileManager.html
- Dog CEO breed-list documentation: https://dog.ceo/dog-api/documentation/
- Dog CEO breed image documentation: https://dog.ceo/dog-api/documentation/breed
- Dog CEO sub-breed documentation: https://dog.ceo/dog-api/documentation/sub-breed

The dependency versions are recorded in `pom.xml`. Runtime dependency licenses and notices remain in their bundled libraries/JAR resources. Dog photo rights remain with their original sources; do not treat downloaded photos as project-owned assets. UI icons are drawn by the project itself.
